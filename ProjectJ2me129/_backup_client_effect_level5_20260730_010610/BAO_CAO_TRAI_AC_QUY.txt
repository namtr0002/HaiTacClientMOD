1. KET LUAN VE MA HOA
============================================================

Khong tim thay lop ma hoa trong cac file {id}.data cua effect 13-55.

Nguyen nhan Java cu khong doc duoc effect 43, 53 va 55 la sai dinh dang parser:
- Frame thuong: dx(short), dy(short), imageId(byte), flip(byte), onTop(byte).
- Frame mo rong: dx(short), dy(short), imageId(byte), 0x80, flip(byte), rotate(short), onTop(byte).

Client luc chay su dung .data; .enc khong phai lop bao ve cua client.

2. DATA CHUA GI VA KHONG CHUA GI
============================================================

Moi effect dong gom:
- {id}.png: sprite sheet.
- {id}.data: vung anh, danh sach frame, vi tri tung manh anh, flip, goc xoay,
  lop tren/duoi, sequence va mot so moc animation.

Data + PNG du de client tu ve animation sau khi DataSkillEff duoc tao.
Data khong tu chua:
- sat thuong;
- cooldown;
- dieu kien dung skill;
- chon muc tieu;
- tru mana/nang luong;
- toan bo trinh tu ghep nhieu effect cua mot skill.

Nhung phan tren phai den tu Effect_Skill client hoac packet/logic server.

Luong tai effect:
DataSkillEff(effectId)
-> kiem tra cache
-> command 74, type 0 xin PNG + data
-> server tra tai nguyen
-> DataSkillEff parse va ve animation.

Luong server gan effect dong:
command 74, type 1
-> target index, effect ID, thoi gian, typeMove, loop
-> MainObject.addDataEff()
-> DataSkillEff tu phat animation.
